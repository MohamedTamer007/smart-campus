# Smart Campus

Graduation project for intelligent campus maintenance, lost-and-found matching, and decision support.

The repository currently contains environment configuration and project requirements. Application code, CI, and application tests have not been added.

Planned stack: React/Vite and plain JavaScript for the website, Node.js/Express for the backend, Transformers.js for pretrained AI inference, and Supabase for managed services. The team must be able to study and explain the implementation without learning Python or TypeScript.

- [Confirmed requirements and environment acceptance criteria](SPEC.md)
- [Verified service configuration and remaining setup](SETUP.md)

Git-triggered Vercel deployments are disabled in [vercel.json](vercel.json) while the repository has no application build. Enable them when application checks and the build are configured.
