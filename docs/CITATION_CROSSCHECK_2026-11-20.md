## Manual acceptance checklist for each row

1. Open the linked original publisher/academic record, not only a secondary summary. Confirm exact DOI/URL, author order, year, title and venue/volume/pagination.
2. Review the located Chapter 2 paragraph and ensure the source actually supports the precise data point, experiment setting and study limitation. Check grouped citations, coauthors and same-year disambiguation.
3. Apply the university-approved citation format consistently, then re-export the PDF and recheck contents, figures and tables. Do not infer school approval from this mechanical report.
4. Mark a reference verified only with a dated reviewer and a link to the original record, or explicitly document a source that cannot be verified. Current default state for all 91: **PUBLISHER/CLAIM REVIEW NOT COMPLETED**.
