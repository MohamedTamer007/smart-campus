# Editable sources for Chapter 3 process diagrams

The three Mermaid files in this folder are **new editable semantic reconstructions** made from the figures displayed in Chapter 3 of the Smart Campus thesis on 20 November 2026. They preserve the named actors, phases, arrows and approval boundaries, but are **not claimed to be the original graphic-design masters or pixel-identical renders**. The three final illustrations embedded in the thesis remain authoritative for their published appearance.

The archive was inspected: 26 paired SVG/PNG renders, figure index, checksum manifest, Mermaid/PlantUML and DBML source files. This folder does not replace that archive.

## Maintenance and correctness
Render the Mermaid diagrams using a trusted Mermaid renderer, then visually compare them to the signed-off thesis figure before substituting images. Any changed workflow must first be confirmed against the source requirements, API state/authorization rules and current tests. No diagram constitutes evidence of actual application behavior on the hosted release.
